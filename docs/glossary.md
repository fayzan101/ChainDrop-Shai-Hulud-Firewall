# Glossary

| Term | Meaning |
| --- | --- |
| Lifecycle script | npm `preinstall`, `install`, or `postinstall` command run during package install |
| Interceptor | Component that extracts those scripts from the dependency graph without executing them |
| Escalate | Classifier decision that sandbox and possibly RAG must run |
| Canary secret | Fake credential placed in the sandbox to detect theft |
| Dead-drop | Attacker use of a public GitHub repo (or similar) as an exfil inbox |
| Held-out generation | ChainDrop data excluded from training and from the evaluation RAG corpus |
| SLSA | Supply-chain Levels for Software Artifacts — build provenance, not a malware scan |
| RAG | Retrieval-Augmented Generation — LLM answers grounded in retrieved documents |
| Quarantine | CI does not proceed to deploy; humans review the verdict |
| EtherHiding | Public name for C2 / payload staging via blockchain data (ChainDrop used an Ethereum contract to rotate domains) |
| Trusted publishing | npm OIDC publish from GitHub Actions without a long-lived npm token |
